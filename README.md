# EZ2FAI

**얼불춤(ADOFAI) 이지투온(EZ2ON) 스타일 판정 오버레이 모드**
**An EZ2ON-style judge overlay mod for A Dance of Fire and Ice (ADOFAI)**
**为《冰与火之舞》(ADOFAI) 打造的 EZ2ON 风格判定面板 Mod**

- 판정 표시 (VL/VE/EP/P/LP/TE/TL) + 정확도 % — judge display + accuracy % — 判定计数 + 准确率
- BPM / 곡 정보 / 진행 바 — BPM / song info / progress bar — BPM / 歌曲信息 / 进度条
- 프로필 이미지, 닉네임, 글꼴 크기, 투명도, 드래그 등 커스터마이징 — customisable (profile image, nickname, font size, opacity, drag) — 可自定义（头像、昵称、字号、透明度、拖动）

설치 / Install / 安装: UMM에서 `Mods\EZ2FAI` 폴더에 넣고 활성화.

GitHub: https://github.com/leo82380/EZ2FAI
